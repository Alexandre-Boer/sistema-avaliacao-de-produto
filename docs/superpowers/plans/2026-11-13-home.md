# Home (Listagem de produtos) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Listar publicamente todos os produtos na home (`/`) com scroll infinito, cada card mostrando imagem, nome (link para `/products/<id>`) e descrição; expor `GET /api/v1/products` paginado e `POST /api/v1/products` para inserção manual.

**Architecture:** A tabela `products` e o tipo `Product`/`toProduct` já existem (Fase 0). Dois serviços server-side (`listProducts`, `createProduct`) usam o client service-role; dois Route Handlers REST os expõem. A home é a página `src/app/(site)/page.tsx` (dentro do layout base com cabeçalho) e renderiza `ProductFeed`, um client component com `useInfiniteQuery` e um sentinela observado por `IntersectionObserver` para carregar a próxima página. Paginação por `offset`/`limit`.

**Tech Stack:** Next.js 16 (App Router, `cacheComponents`), React 19, TanStack Query (`useInfiniteQuery`), zod, nanoid, `next/image`, shadcn/ui (`card`, `skeleton`, `badge`, `button` já instalados), Vitest + Testing Library.

**Spec:** `specs/home.md` (ver também `docs/superpowers/plans/2026-11-13-orquestracao.md` para contratos e donos de arquivos)

## Global Constraints

- `GET /api/v1/products` retorna `200` sempre (lista vazia quando não há produtos); `POST /api/v1/products` recebe `name`, `description?`, `externalLink`, `imageUrl` e retorna `201 { id }` ou `400`.
- `id` gerado com `nanoid()` na camada de API (serviço).
- Cada produto mostra título, imagem e descrição simples; clicar no **nome** navega para `/products/<id>` (a página de detalhes é entregue pela feature Feedback; aqui só o link).
- Home pública, sem autenticação.
- Não editar arquivos de outros donos (ver orquestração): `src/server/products/product.ts`, `src/components/layout/**`, `src/app/(site)/layout.tsx`, migrations, `package.json`.
- Lint/format com Biome; TypeScript estrito.

## Review Focus

1. **Última página:** quando o banco devolve menos itens que `limit`, `nextOffset` deve ser `null` e o feed para de buscar. Testes: Task 2 (passo 1, "nextOffset null na última página") e Task 4 (passo 1, "não busca além da última página").
2. **Query string inválida** (`limit=abc`, `limit=1000`, `offset=-1`) não pode virar `500`: o schema de query usa `coerce`, limites `1..50` e default `12`. Teste: Task 1 (passo 1, casos de query).
3. **Produto sem imagem/descrição** (`image_url`/`description` nulos) deve renderizar um placeholder em vez de quebrar. Teste: Task 4 (passo 1, "renderiza placeholder sem imagem").
4. **Erro de rede na listagem** deve mostrar mensagem e botão "Tentar novamente", não tela em branco. Teste: Task 4 (passo 1, caso erro).
5. **`externalLink` sem protocolo** (`www.loja.com`) deve ser rejeitado pelo `POST` com `400`, não salvo quebrado. Teste: Task 1 (passo 1, "rejeita externalLink inválido").
